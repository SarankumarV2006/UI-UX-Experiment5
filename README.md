# UI-UX-Experiment5

## Aim:
To Present 2 different UX project scenarios (e.g., designing a health app, an e-commerce site, or a government service portal).

## Algorithm:
First, I selected two different UX project scenarios — a Health & Fitness Tracking App and an E-Commerce Platform for Local Handicrafts.

I identified the user problems and goals for each scenario using the problem statement format:
"[User] needs a way to [achieve goal] because [obstacle], which results in [impact]."

Then, I chose the appropriate research methods such as surveys, interviews, and usability testing to understand user needs.

Based on the collected data, I created two user personas for each project with their demographics, goals, behaviors, pain points, and motivations.

I designed the user interface layouts in a clean and structured way, keeping user flow and accessibility in mind.

Finally, I presented the design output visually, showing how each persona’s goals are supported by the app features.
